# Noctiluca

Noctiluca 是用 Rust 和 Ely GPUI 编写的 Windows 原生 Minecraft Java 版启动器。双击 `Noctiluca.exe`，从侧栏添加账号，选择实例并点击「启动游戏」。将本地整合包拖入窗口，或点侧栏「＋」后选择「导入整合包」。拖入后会自动读取清单，并预下载可直接获取的必需文件。预览会显示包名、来源、Minecraft 版本和加载器。需要补文件时，底部可以选择已下载文件；也可展开「可选文件」勾选附加内容。文件齐备后，点「仅安装」或「安装并启动」。首次安装会准备游戏、资源和清单中指定的加载器。

## 实例与文件

- 「＋ → 新建实例」可搜索游戏版本，通过左右箭头翻页。选择原版或指定加载器构建，点击「创建并安装」准备游戏、运行库、资源和所选加载器。实例名称留空时使用加载器和游戏版本。
- 「发现内容 → 整合包」支持按加载器、游戏版本、名称和来源查找整合包。选择发布版本后，启动器按包清单安装到独立实例。本地可导入 Modrinth 的 `.mrpack`、CurseForge 或 MultiMC/Prism 实例的 `.zip`。MultiMC 支持外层实例目录和常用加载器，自定义组件补丁会提示具体原因。如果基础游戏准备中断，选中已创建的实例，点击「安装 / 修复」继续。
- Modrinth 可以直接使用。发布者可用 `NOCTILUCA_CURSEFORGE_SERVICE` 指定自己的 HTTPS 服务根地址（兼容官方 v1 路由，可在构建时设置）。直连官方 API 的开发环境使用 `NOCTILUCA_CURSEFORGE_API_KEY`。未接入服务的发行版会在 CurseForge 请求时提示。文件须经作者授权第三方下载，目前支持模组、资源包和光影三种 CurseForge 文件类型。[CurseForge API](https://docs.curseforge.com/rest-api/)
- 「实例管理」按加载器分组，可按名称、游戏版本或加载器搜索。点「添加已有目录」，选择 .minecraft、包含它的文件夹，或 versions 下的单个版本目录，扫描后在版本旁点「启动游戏」。游戏使用原目录的版本、运行库、资源、模组和存档。支持共用游戏目录与版本隔离目录。旧版已经复制过的实例仍使用各自的存档。
- 一个实例启动后可以回到侧栏启动另一个。各实例有独立的进程、日志、存档、模组目录和本地 DLL 目录。运行状态与进程号显示在「实例管理」。同一实例持有独占锁，公共游戏资源的安装依次进行。

- 游戏版本目录从 Minecraft 1.17 起，默认显示正式版。「含快照」可浏览或搜索快照。Fabric、Forge、NeoForge 和 Quilt 的构建按所选游戏版本查询。
- 「发现内容」可搜索模组、整合包、资源包和光影。下载模组时选择目标实例，再选择兼容的发布版本。文件写入该实例实际使用的游戏目录，关联的外部实例会使用原目录。资源包和光影按同样的步骤安装，整合包则进入导入预览。
- 每个实例分别保存存档、设置、资源包与模组。可以为相同的游戏版本建立多个实例，设定不同的 Java、内存、JVM 参数和窗口分辨率。
- 「安装 / 修复」可单独执行下载与校验。已完成的文件会在重试时复用。「启动设置」中的共享资源来源可以指向已有的 `.minecraft`，安装器按清单和 SHA-1 验证后复制匹配的文件。
- 「备份与克隆」可以保存当前实例、复制游戏目录，或从本地备份恢复为一个新实例。备份包括世界、模组与配置。大型实例需要相应的额外磁盘空间。
- 「管理模组」按加载器和游戏版本搜索 Modrinth，安装模组及必需依赖，并可停用或重新启用本地 JAR。「导入整合包」按整合包指定的加载器版本导入必需客户端文件、通用配置和客户端配置。可选文件默认不勾选。缺少自动下载来源时，可打开文件页或在 Modrinth 查找，再选择本地文件。校验通过后即可继续。网络下载失败也可在预览中重试或手动补齐，当前导入会话会复用已校验的文件。
- 「实时控制台」每秒更新当前日志的末尾，最多展示 100 行、32 KiB。可切换游戏、启动器与加载器日志，打开原始文件，或复制已遮盖常见令牌的片段。
- 可以给实例建立 Windows 快捷方式。例如目标参数 `--launch fabric-1.20.1` 会直接启动内置 Fabric 实例。自建实例的 ID 在其 `instance.json` 中。

在实例详情中，「游戏内存」支持跟随全局、自动和自定义。自定义模式分别调整初始内存（-Xms）与最大内存（-Xmx），下方显示当前系统用量与游戏分配。

点击「删除实例」并确认后，整个实例会移入已删除实例区。打开「实例管理 → 已删除实例」可恢复世界、模组与配置。

启动时优先使用实例指定的 Java。自动检测会检查系统环境变量、PATH、常见 JDK 安装目录和已安装的游戏运行时。优先匹配游戏要求的主版本，其次复用高于要求且版本最接近的 Java。找不到符合版本要求的本机 Java 时才下载 Mojang 运行时。针对要求特定 Java 的模组，可在「启动设置」指定可执行文件。

默认采用便携布局。程序与数据请放在可写目录中。

```text
Noctiluca.exe
Noctiluca-data/
  instances/<实例 ID>/instance.json
  instances/<实例 ID>/game/
  instances/<实例 ID>/launcher.log
  instances/<实例 ID>/last-launch.log
  shared/                              游戏文件、Java、运行库和公共资源
  removed-instances/<实例 ID>/         已移除的完整实例
  backups/<实例 ID>/                   本地备份
```

新安装使用 `Noctiluca-data`。升级时，程序旁只有 `MCSTART-data` 就继续使用原数据。`NOCTILUCA_HOME` 可指定数据目录，`NOCTILUCA_JAVA` 可指定默认 Java，`NOCTILUCA_CACHE_SOURCE` 可指定既有游戏缓存。旧版对应的 `MCSTART_` 环境变量仍可使用。

## 实例内容与整合包

- 点击实例中的「模组」「资源包」「光影」「存档」「截图」「投影」查看该目录内容。「在资源管理器中打开」进入实际游戏目录。模组、资源包、光影支持从本地添加，资源包和光影也可按游戏版本搜索 Modrinth 并安装。
- 「管理模组」可从 Modrinth 或已接入的 CurseForge 安装项目、检查本地 JAR 的兼容更新。选中更新后会校验旧文件，保留停用状态，在游戏目录旁保存更新前的模组目录。
- 「组件与整合包」可为托管实例切换 Forge、NeoForge、Fabric 或 Quilt 的构建。启动器先准备新版组件，成功后才应用到实例。
- 从「发现内容」安装的整合包可检查在线更新。从文件导入的 Modrinth 包也能按归档哈希查找其发布项目。自制包与 MultiMC 包可用「选择本地新版包」更新。升级会在同一实例保留存档、额外文件及已修改的配置，遇到无法合并的同名文件会停止。成功后可从本页回滚。旧版导入的实例没有文件清单，第一次更新会保留归属未知的文件。
- 导出时选取模组、配置、资源包或光影，保存为可再次导入的自包含 `.mrpack`。压缩包只包含所选分类及版本清单，请确认可以分发所选文件。
- 实时控制台的「导出脱敏诊断包」汇集游戏输出、加载器日志、最近的崩溃报告与依赖提示。文件保存在所选目录。

## 启动器设置

侧栏「设置」作用于整个启动器。实例的 Java、分辨率和内存可单独覆盖全局默认值。

- 「启动」管理已有目录的隔离识别、游戏窗口标题、窗口大小、启动器可见性、进程优先级与 Java 的 IP 协议偏好。
- 「Java 与内存」选择本机 Java，可单独设置初始与最大内存。
- 「下载管理」可为版本列表和游戏文件分别指定官方源或 BMCLAPI 优先，设置 HTTP 协议、并发、分段连接和限速。多连接适用于支持 HTTP Range 的大文件。可选的 Authlib 修订仅采用本机已有、官方版本清单可校验、主次版本相同的更新。
- 「内容与辅助」设置社区下载平台、文件命名、列表样式、快速安装、必需依赖、Quilt 显示和版本提示。开启剪贴板识别后仅在窗口激活时提示打开支持的社区链接。
- 「外观与语言」提供三种冷色强调色和游戏语言设置。「联机」可配置启动后直连的服务器。「关于」可检查公开发行版、前往下载或反馈、查看当前实例日志。

## 游戏账号

侧栏底部显示当前角色的头像、游戏名和登录类型。点击账号行可切换或添加账号，也可管理皮肤、头像和角色名。

- **离线** 输入角色名即可添加。首次安装游戏需要下载资源。服务器是否接受该身份取决于服务器的认证设置。选取本地皮肤 PNG 可以设置启动器里的头像。
- **Microsoft** 点击「微软正版登录」。Noctiluca 会显示并复制一次性代码，自动打开微软验证页。也可以在手机上打开弹窗里的网址完成授权。成功后自动显示 Java 角色，刷新令牌存放在 Windows 凭据管理器。
- **第三方** 填写认证站提供的 Yggdrasil HTTPS API 根地址和该站账号。多角色账号可指定角色名。游戏使用与该站配套的 authlib-injector 登录。[authlib-injector 项目](https://github.com/yushijinhun/authlib-injector)

启动器默认使用 Noctiluca Launcher 的公开客户端 ID。使用自有应用构建时，可通过 `NOCTILUCA_CLIENT_ID` 覆盖。旧版保存的服务配置继续生效。应用需支持个人微软账号、启用公共客户端流，并具备 Minecraft 服务访问权限。[微软设备代码协议](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-device-code)

## 从源码构建

使用 Windows x64、Rust MSVC 工具链、Visual Studio C++ 构建工具、Windows SDK（含 `fxc.exe`）与 CMake。推荐在 Visual Studio 开发者终端中运行。依赖首次下载需要能访问 GitHub 和 crates.io。

```powershell
cargo run --locked
cargo test --locked
cargo build --release --locked
```

发布版生成在 `target/release/noctiluca.exe`。图标、字体与发布版 DirectX 着色器会随程序一起编译。项目固定了 Ely 和配套 GPUI 的版本。[Ely GPUI](https://github.com/ZacharyZhang-NY/Ely-GPUI-Components) · [Minecraft 启动内核](https://docs.rs/mc-launcher-core/0.1.2/mc_launcher_core/)
