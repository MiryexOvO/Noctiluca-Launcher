# Noctiluca

Noctiluca 是 Windows 上的 Minecraft Java 版启动器。你可以把整合包拖进来直接安装，也可以用它打开电脑上已有的游戏和存档。

## 第一次玩

1. 把 `Noctiluca.exe` 放进一个可以保存文件的文件夹，双击打开。
2. 点侧栏的账号区域添加角色。用微软账号就在浏览器里输入授权码，用第三方账号就填认证站提供的地址和账号。想离线玩，起个游戏名就行。以后可以点头像切换角色。
3. 点实例库旁的「＋」，搜索想玩的 Minecraft 版本。玩原版就选「原版」，装模组可以选 Fabric、Forge、NeoForge 或 Quilt，再挑对应的加载器版本。点「创建并安装」，准备好后点「启动游戏」。

侧栏会优先显示整合包自己的图标。名字太长时，把鼠标停在名字上就能看全。

一个实例就是一套游戏配置。比如可以建一个原版生存，再建一个同版本的 Fabric 实例专门玩模组。版本列表从 1.17 起，打开「含快照」还能找到快照版。启动器会优先用电脑上合适的 Java，缺少时才下载。

## 装整合包

手上已经有包的话，把 Modrinth 的 `.mrpack`、CurseForge 或 MultiMC / Prism 的整合包 `.zip` 拖进窗口。预览里能看到游戏版本、加载器、可选模组，以及这一包文件还要下载多大。游戏本体、Java 和加载器会在安装时另外检查。还没选好包的话，可以去「发现内容 → 整合包」搜索，选好版本就能预览。

有些模组需要自己到作者的下载页获取。把下载好的几个文件一起拖回预览，或者点「扫描文件夹」选浏览器的下载目录，子文件夹也会一起找。即使浏览器把文件改成了 `模组名 (1).jar`，只要内容和整合包要求的一样，就能认出来。还缺哪几个，预览里会继续列出来。

准备好后点「仅安装」或「安装并启动」。以后想更新，在实例的「组件与整合包」里检查新版。自己做的包也可以选本地新版文件。更新会保留存档和自己添加的文件，有配置冲突时会提示。想分给朋友，可以挑选模组、配置、资源包或光影，导出成 `.mrpack`。

## 装模组、资源包和光影

在「发现内容」里搜索项目，点「下载」，选择要装到的实例。列表会告诉你这个实例里已经装了哪个版本、有没有新版。选定实例后，可以在兼容版本旁看到下载大小。

手上有文件的话，把模组 JAR、资源包或光影 ZIP 拖到侧栏里的实例名上，也可以先打开实例再拖进窗口。确认页会显示要装到哪个实例。遇到同名文件可以跳过或替换，认不出的 ZIP 可以手动选类型。

如果两个实例共用同一个模组目录，安装按钮上方会列出另一个实例的名字。在这里装一个模组，两边的游戏都会读到它。资源包和光影也会提示各自的共用目录。

打开实例的「管理模组」，输入模组名、模组 ID 或 JAR 文件名就能查自己装过的模组。点「已停用」能找到关掉的模组，点「有更新」会用选中的平台检查兼容版本。要找新的模组，点「查找新模组」。换新版时，原先停用的模组会继续保持停用。Modrinth 可以直接使用。CurseForge 在线搜索和下载需要发行版接入相应服务。

## 已经有游戏或存档？

打开「实例管理 → 添加已有目录」，选择原来的 `.minecraft`、它的上级文件夹，或 `versions` 下某个版本的文件夹。选好后就能在 Noctiluca 里启动，存档和模组继续从原目录读取。旧版本启动器里已经复制过来的实例会继续使用自己的副本。

- **多开游戏**　启动一个实例后，回到侧栏选择另一个。运行中的实例可以在「实例管理」里看到。
- **调整内存或 Java**　日常使用可以交给自动配置。大型整合包有特别要求时，在该实例的「启动设置」里指定 Java、内存或窗口大小。侧栏的「设置」可以改所有实例的默认值、下载源和限速。
- **备份一个世界**　打开实例的「存档」，按世界名、缩略图和上次游玩时间找到自己的地图，退出游戏后点旁边的「备份」。想回到之前的进度，就点「备份记录 → 恢复为新世界」。恢复出来的世界带有日期，原世界照常保留。即使原世界已经删除，也能从「全部备份」找回来。
- **备份整个实例**　打开「备份与克隆」，可以连同模组和配置一起保存，也可以复制一份实例，用来试新模组。误删的实例可以去「实例管理 → 已删除实例」找回。
- **启动遇到问题**　游戏文件没下全时，点「安装 / 修复」接着装。启动失败后，实例页会显示原因。能识别出缺少哪个模组时，点「查找兼容版本」就会带着模组 ID 搜索。其他问题可以打开日志，或导出诊断包给帮你排查的人。

## 数据放在哪里？

默认保存在启动器旁边的 `Noctiluca-data` 文件夹。搬到另一台电脑时，把它和 `Noctiluca.exe` 一起带走。通过「添加已有目录」关联的游戏也要单独带走。如果原来用的是 `MCSTART-data`，启动器会继续识别旧目录。

<details>
<summary>自定义路径和快捷方式</summary>

- `NOCTILUCA_HOME` 指定启动器数据目录，`NOCTILUCA_JAVA` 指定默认 Java，`NOCTILUCA_CACHE_SOURCE` 指向可以复用的游戏资源。旧版的 `MCSTART_` 环境变量也可以继续用。
- 可以给常玩的实例建一个 Windows 快捷方式，在目标后面加上 `--launch 实例ID`。实例 ID 可以在 `instances/<实例 ID>/instance.json` 中找到。

</details>

## 从源码构建

Noctiluca 使用 Rust 和 Ely GPUI。Windows x64 下需要 Rust MSVC 工具链、Visual Studio C++ 构建工具、带 `fxc.exe` 的 Windows SDK 和 CMake。在 Visual Studio 开发者终端进入源码目录，运行下面的命令。

```powershell
cargo build --release --locked
```

生成的程序位于 `target/release/noctiluca.exe`。开发时也可以用 `cargo run --locked` 直接启动。

自己发布启动器时，可通过 `NOCTILUCA_CLIENT_ID` 配置已获 Minecraft 服务访问权限的微软应用。CurseForge 可通过 `NOCTILUCA_CURSEFORGE_SERVICE` 接入兼容官方 v1 接口的 HTTPS 服务，本地开发直连官方接口时可设置 `NOCTILUCA_CURSEFORGE_API_KEY`。[微软设备代码登录](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-device-code) · [CurseForge API](https://docs.curseforge.com/rest-api/) · [Ely GPUI](https://elygpui.com)
